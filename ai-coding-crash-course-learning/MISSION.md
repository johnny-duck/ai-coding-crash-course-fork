# Mission: Navigating the AI Coding Crash Course repo

## Why
Complete Matt Pocock's AI Coding Crash Course. The course has me use Claude Code to explore and extend a React Router + TypeScript + SQLite app. As a Java/Spring Boot backend engineer with no front-end experience, I need enough understanding of this codebase to steer the agent and judge what it does, without getting stuck on unfamiliar front-end code.

## Success looks like
- Given a URL in the app, I can find the route file, its loader/action, and the service + table it touches
- I can write precise Claude Code prompts that name the right files and layers
- I can skim a Claude-generated diff and say which layer it touched and whether that layer makes sense
- I can run the app, the tests, and the typecheck, and read their output
- I finish all six course sections without front-end confusion blocking me

## Constraints
- About 15 minutes per session: short lessons, one win each
- Strong Java/Spring background. Use Spring analogies where they hold up, and say clearly where they break down.
- Goal is to **navigate and steer**, not to write React by hand

## Out of scope
- Mastering React, CSS or Tailwind in depth
- Hand-writing complex UI components
- Front-end tooling internals (Vite, bundling) beyond what the course needs
