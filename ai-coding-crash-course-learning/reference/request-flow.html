URL → file

  1. Find the pattern in app/routes.ts
  2. File naming convention: . = /, $x = :x
  3. /courses/:slug/lessons/:lessonId
    → courses.$slug.lessons.$lessonId.tsx
  4. params.slug holds the URL segment

Route module exports

  • loader: GET data (server)
  • action: mutations (server)
  • default: the component (UI)
  • meta: <title> and meta tags
  • ErrorBoundary: error UI
