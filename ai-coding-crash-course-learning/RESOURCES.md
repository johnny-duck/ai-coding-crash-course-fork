# AI Coding Crash Course Repo Resources

## Knowledge

- [Course: AI Coding Crash Course (Matt Pocock, AI Hero)](https://www.aihero.dev/workshops/ai-coding-crash-course)
  The course this repo belongs to, with about 60 lessons in 6 sections. Use for: what the course actually needs you to understand at each step.
- [Repo README: `../README.md`](../README.md)
  The tech stack, the scripts (`dev`, `test`, `typecheck`, `db:migrate`, `reset`, `cherry-pick`) and the course structure. Use for: running things and jumping between lesson checkpoints.
- [Docs: React Router: Routing (Framework Mode)](https://reactrouter.com/start/framework/routing)
  Official docs for `app/routes.ts`: `route()`, `index()`, `layout()` and `:dynamic` segments. Use for: mapping a URL to a file.
- [Docs: React Router: Route Module](https://reactrouter.com/start/framework/route-module)
  Official docs for the exports of a route file: `loader`, `action`, the default component, `meta` and `ErrorBoundary`. Use for: what each part of a route file does and where it runs.
- [Docs: Drizzle ORM overview](https://orm.drizzle.team/docs/overview)
  "If you know SQL, you know Drizzle." Use for: reading `app/db/schema.ts` and the queries in `app/services/*`.
- [Docs: react.dev: Quick Start](https://react.dev/learn)
  The official React intro: components, JSX, props and state. Use for: reading the default-export component in a route file.

## Wisdom (Communities)

- [AI Hero FAQ / support](https://www.aihero.dev/faq). The course page lists team@aihero.dev for support.
