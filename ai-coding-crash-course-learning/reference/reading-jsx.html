Reading JSX

A component is a function: loaderData goes in, markup comes out.

The five patterns

Lowercase vs Capitalized

  • <div> <span> <h1>: plain HTML
  • <Card> <Button>: ~/components/ui/* (shadcn/ui)
  • <Link to>: react-router, navigation without a full reload
  • <PlayCircle> and similar: lucide-react icons

Syntax decoder

  • className: the HTML class attribute (Tailwind, skip it)
  • const {a, b} = obj: destructuring
  • `text ${x}`: template literal
  • =>: lambda (Java's ->)
  • style={{ w: 1 }}: an object literal inside { }
  • {/* … */}: a comment in JSX

JSX diff review checklist

  1. Each new {value} traces back to loaderData → loader → service
  2. No number on the left of &&. count && … renders 0, so use count > 0 && …
  3. .map items have a stable key (an id, not the index)
  4. No data fetching inside the component. In this repo, it belongs in the loader
